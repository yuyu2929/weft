# Weft 理论设计：一种统一的矢量-栅格数据结构

> 名称：**Weft**（纬纱）。比喻：网格骨架是**经线**（warp，固定、可寻址），
> 跨格要素是**纬线**（weft，一次织入、纵横穿过多个格而不被剪断），
> 叶子里的积分栅格场是织成的**布面**——从经纬中自然生出、可拆了重织。
> 定位：面向企业与工程管线的 2D 平面域统一表示（城市、地籍、管线、矿区、厂区）。

---

## 1. 设计目标（从 RESEARCH.md 的对照表反推）

| 目标 | 继承自 | 消除的缺点 |
|---|---|---|
| G1 单一整数地址、范围扫描即空间扫描 | Geohash / quadkey | Geohash 面积不等、Z 序局部性断裂 |
| G2 全局局部性（Hilbert 序） | S2 | S2 的球面变换开销、ID 不透明 |
| G3 要素一次存储、跨格不切割 | GeoParquet/FlatGeobuf | MVT 的边界切割与重复存储 |
| G4 跨格边界可精确缝合、可审计 | （MVT 的 buffer+id 的严格化） | MVT 去重只能靠 id、buffer 冗余 |
| G5 叶子积分栅格场：栅格查询 O(1)、误差有界、可从矢量重算 | value-quadtree (2026) 的实证 | COG 栅格即数据、不可局部编辑 |
| G6 叶子级版本 + 脏格增量更新 | 软件工程的 copy-on-write | COG 整文件重生、MVT 重切一片 |
| G7 确定性序列化 + 内容哈希 | 可复现工程管线 | 浮点/字典序不确定导致不可 diff |

## 2. 数学定义

### 2.1 域与细分

域为有界矩形 $\mathcal{D} = [0,W)\times[0,H)$（平面 CRS，如局部米制）。
设最大深度 $D$（默认 20）。深度 $d$ 的细分是 $2^d \times 2^d$ 的均匀网格，
格 $(d,x,y)$（$0\le x,y<2^d$）的矩形为

$$\mathrm{rect}(d,x,y)=\Big[\tfrac{xW}{2^d},\tfrac{(x+1)W}{2^d}\Big)\times\Big[\tfrac{yH}{2^d},\tfrac{(y+1)H}{2^d}\Big).$$

**同层格子面积严格相等**（平面均匀细分），层间面积比恒为 4——这是 Geohash
（经纬度格、高纬面积畸变）与 H3（全局等面积但五边形例外）之间取中的正确选择：
工程域有界、投影已知，等面积是构造性保证而非近似。

### 2.2 地址：Hilbert quadkey（复合 uint64 打包）

对每个深度 $d$，用 **Hilbert 曲线**给 $2^d\times2^d$ 个格编号
$h_d(x,y)\in[0,4^d)$（标准 xy2d 旋转算法，纯整数运算、与 d2xy 互逆）。
地址（key）定义为**复合 uint64**：

$$\mathrm{key}(d,x,y) \;=\; (d \ll 40)\;|\;h_d(x,y).$$

**为什么这样打包**（docs/DEVLOG.md 有三次设计失败的完整记录）：
- 左对齐 $\mathrm{key}=h_d\cdot4^{D-d}$：父键是子键前缀 $\Rightarrow$ **父与第 0 子同键**
  （鸽笼原理：4 子 + 父 = 5 个串挤进下一尺度的 4 个槽位），树退化为 4 格永不分裂；
- 右对齐 $\mathrm{key}=h_d$：不同深度的键空间重叠 $\Rightarrow$ 深度 1 的键 0..3
  撞上深度 2 格的子 0..3；
- 深度放低位：覆盖 $h$ 低位，同深度内不再单射。
**深度-高位 + Hilbert-低位是唯一同时满足 单射 / 可除 / 可算 的打包。**

**引理 1（祖先后裔测试）**：格 $A=(d_A,x_A,y_A)$ 是格 $B=(d_B,x_B,y_B)$ 的
祖先或自身 **当且仅当** $d_A\le d_B$ 且
$\big(h_{d_B}(B)\gg 2(d_B-d_A)\big)=h_{d_A}(A)$——两次整数运算，无指针。

由此得到全部地址运算，全部是整数运算：

| 运算 | 公式 |
|---|---|
| 深度 | `key >> 40` |
| 父 | `((d-1) << 40) \| (h >> 2)` |
| 四子 | `[((d+1) << 40) \| ((h << 2) \| t), t∈{0,1,2,3}]` |
| 祖先后裔测试 | 引理 1（两次整数运算） |
| 后代叶子枚举 | `descendant_intervals`：**每层一个整数区间**，至多 $D$ 个 |
| 同层邻居 | 由 (x,y) 直接 ±1，越界即无（域有界，**无换日线问题**） |

**如实声明的代价**：复合键下跨层后代**不是**单一整数区间，而是每层一个区间
（至多 $D$ 个，见 `address.descendant_intervals`）。这是换取"深度可恢复 +
键全局单射"的必要代价——范围扫描按层枚举；bbox/KNN 查询本就走树下探，
不依赖单一区间。存储布局因此是 depth-major（按键分层），层内是纯 Hilbert 序。

**与 Z-order 的区别**：Z-order（Morton / Geohash / 传统 quadkey）的层级数字
是坐标位交错，空间聚类在象限边界断裂；Hilbert 序下小区域查询的键序**连续段数**
显著更少（基准 [7]：3×3 邻域平均 1.9 段 vs Morton 2.2 段）——范围扫描、
页打包、CDN 缓存命中都受益。代价仅是编解码每层多几次整数旋转
（$D\le20$，热点路径仍是纯整数）。

### 2.3 要素块（feature block）与缝合计账本（stitch ledger）

要素 $f$（点/线/面）整体存储一次：

$$f = (\mathrm{fid},\ \mathrm{layer},\ \mathrm{geom},\ \mathrm{props}).$$

- **fid**：稳定 64 位整数 id（写入时分配，删除不复用）——MVT 生态反复强调
  "没有 id 就无法去重/无法 feature state"，Weft 把 id 变为结构内建属性。
- **geom**：坐标数组（float64），**绝不按格边界裁剪**。
- **格引用**：$f$ 记录其几何相交的所有叶子 $\mathrm{cells}(f)\subseteq\mathrm{keys}$
  （覆盖格集合，见 2.6 的选深规则）；每个叶子反向记录 `feature_ids`。

**缝合计账本**记录跨格边界的通过事件：

$$\mathrm{ledger} = \{\,(\mathrm{key}_a,\mathrm{key}_b,\mathrm{fid}) : \text{格}_a,\text{格}_b \text{ 共边且同属 } f\,\}.$$

三个用途（对应 MVT 的三个顽疾）：
1. **拾取/查询完备性**：命中任一格 → 经 `cells(f)` 拿到**完整**几何
   （不是 MVT 的 buffer 残段）；区域查询跨格不重复（几何只存一份，
   按 fid 天然去重）。
2. **边界审计**：`crossings(key_a, key_b)` 直接回答"哪些要素穿过这条格界"——
   工程上的断层线/缓冲带分析是一等查询。
3. **脏格推导**：编辑 $f$ 只需重算 $\mathrm{cells}(f)$（账本给出精确集合），
   无关格零代价。

**引理 2（存储无重复）**：Weft 中要素几何的总字节数 = 唯一要素的字节数，
与要素跨多少格无关。*证明*：几何仅存于要素块；格内只存 fid 引用与
（可选的）量化部件索引，均为 $O(1)$ 定长。∎
（MVT 的对应量为 $O(\text{跨格数}\times\text{buffer})$。）

### 2.4 叶子积分栅格场（integral raster field）

每个叶子格 $c$ 携带一个**导出场**：

$$\mathrm{field}_c\ \in\ \mathbb{R}^{r\times r\times L},\qquad r=\text{field\_res（默认 8）},$$

第 $\ell$ 层在第 $(i,j)$ 子格上的值语义（按层类型）：

| 层类型 | 场值语义 | 精确性 |
|---|---|---|
| 面层 | 该子格被本层多边形覆盖的**面积占比** $\in[0,1]$ | 蒙特卡洛上采样估计，误差有界（见引理 3） |
| 点层 | 落入该子格的点数 | **精确**（整数） |
| 线层 | 线段在子格内的**长度密度**（长度/子格宽） | 精确（裁剪解析计算） |

**引理 3（场误差界）**：面层场值用 $s\times s$ 子采样估计（默认 $s=4$，即每子格
16 个采样点），对任意子格，估计值 $\hat p$ 与真实覆盖率 $p$ 满足
$|\hat p - p|\le 1/s^2$（确定性最坏情形：全部采样点误分类），且
$\mathbb{E}|\hat p-p|\le \tfrac{1}{2s}$。查询接口**必须**返回该界，
调用方据此决定是否回落到精确几何测试。

**关键性质**：
1. **可重算性**：场由 $\mathrm{cells}(c)$ 内的矢量要素完全决定——
   $\mathrm{field}_c=\mathcal{F}(\{f : c\in\mathrm{cells}(f)\})$。
   矢量是权威，场是索引/加速器；**任何时候都能从矢量精确重建**
   （COG 的栅格即数据，丢了矢量语义，编辑必须重生整文件）。
2. **增量性**：编辑只重算脏格（引理：只有 $\mathrm{cells}(f)$ 受影响）。
3. **查询不对称性利用**：`field_at(ℓ,x,y)` 是 $O(1)$（算 key、索引数组）；
   精确查询回落到 PIP。读多写少的工程负载（监测、仿真前处理）收益最大。

### 2.5 版本、脏格与日志

- 每叶带 `version: uint64`；每次重算 +1。
- 编辑日志 $\mathcal{J}=\{(v,\ \mathrm{op},\ \mathrm{fid},\ \mathrm{keys})\}$，
  checkpoint = 全量内容哈希。两个 snapshot 的 diff = 按键集合差，
  天然支持工程审计（"这批改了什么"）。
- 序列化**确定性**：所有字典序显式排序；浮点用 `struct.pack('<d')`；
  无墙钟时间戳（版本号即逻辑时钟）。同输入 → 逐字节同输出 → 内容哈希可比。

### 2.6 插入算法：自适应四叉分区（不是"每要素自选深度"）

Weft 的叶子构成域的**分区**（partition），不是"每要素自选深度"的 overlap 集合。
分区纪律保证两条不变式：

- **(I)** 任意点 $p$ 至多属于一个已存叶子；
- **(II)** 包围盒覆盖 $p$ 的每个要素都注册在 $p$ 所在的叶子里。

`insert(f)`：
1. 分配 fid；把 $f$ 加入要素块；
2. **定位**：从根沿 bbox 裁剪的递归覆盖（点要素走 `cell_of` 式半开归属上溯，
   面/线走含边界接触的 AABB 下沉）找到所有相交叶子；不相交剪枝，空区域建叶；
3. **分裂**：叶内要素数超过阈值（默认 32）且未到最大深度 → 四分，
   按 bbox 相交重分发（含边界规则，点要素半开规则）；
4. 对每格 `c`：把 fid 加入 `c.feature_ids`，更新缝合计账本（同层共边格对）；
5. 标记这些格 dirty；提交时按格重算场（引理 3 的估计器）并 +1 版本。

(I)(II) 由"沿 bbox 裁剪的递归覆盖 + 超限分裂重分发"归纳维持：
基例（单叶）显然；分裂步中，父叶的全部要素按"与子格 bbox 相交"重分发，
每个要素的覆盖格集合恰好更新为新的相交叶集合（引理：bbox 与父格相交的
要素必与至少一个子格相交——子格矩形拼接父格矩形）。∎

**点要素的半开规则**：点归属用 $\mathrm{rect}[0]\le p_x<\mathrm{rect}[2]$
（与 `cell_of` 的 `int(p_x/w·2^d)` 归一化逐位一致），否则 $x=0$ 边界的点会被
所有格子的"内部重叠"判定剪掉（见 DEVLOG 边界退化记录）。

**写放大上界**：一次编辑触碰 $|\mathrm{cells}(f)|$ 格（跨格要素按覆盖计），
分裂级联止于局部；与总格数无关。

## 3. 操作与复杂度

设 $n$ = 要素数，$m$ = 叶子数，$k$ = 查询返回数。

| 操作 | 复杂度 | 说明 |
|---|---|---|
| `field_at(ℓ,x,y)` | $O(1)$ | 算 key + 数组索引 |
| `query_point`（精确） | $O(\log m + t)$ | 沿 key 下落（整数运算）+ 该格要素的精确测试 |
| `query_bbox` | $O(k+\log m)$ | key 空间递归：内含子树整段取、相交下沉 |
| `knn(ℓ,x,y,k)` | $O((k+\log m)\log m)$ | 最佳优先：堆按"查询点到格矩形下界距离"展开 |
| `insert/delete/update` | $O(|\mathrm{cells}(f)|\cdot r^2)$ | 只碰受影响叶 |
| `crossings(a,b)` | $O(\log m + t)$ | 账本按键对索引 |
| `reconstruct(fid)` | $O(\mathrm{size}(f))$ | 几何一次存储，直接读 |
| `rasterize(bbox)` | $O(\text{输出尺寸})$ | 场上采样/双线性，无需重算几何 |
| `serialize` | $O(m+n)$ | 排序后线性写 |

## 5. 诚实的能力边界（README 同样声明）

1. **单文件单有界矩形域**。不做全球球面（那是 S2/H3 的领域）；多域用多文件 +
   目录层，v1 不做。
2. **纯 2D**。无高程/时间维；Zarr/GeoZarr 是高维数据立方体的更好答案，
   Weft 不假装覆盖。
3. **面层场是估计值**（引理 3 的界内）。精确答案必须回落几何测试——
   Weft 提供开关，不承诺"栅格即精确"。
4. **原型规模**：单机内存版。企业级分片（按键区间分节点）、多写者日志合并
   走 `enterprise` 门控路径，本仓库提供接口与单机实现。
5. **不是 PostGIS 替代品**：SQL 生态、任意拓扑运算、投影系谱不在范围。
   Weft 的战场是"矢栅同存、读多写少、要可复现交付物的工程管线"。

## 6. 为什么这个交集此前是空的（贡献陈述）

- Li-Deren（1992）证明了"一份 Morton 编码可同读矢栅"，但停留于编码论文：
  无版本、无增量、Z 序局部性断裂、无工程协议。
- QR-tree（2003）混合了四叉与 R 树，但是**纯索引**，不含数据语义。
- value-quadtree（2026）实证了栅格化加速 PIP 且精度可控，但是**查询期转换**，
  非存储结构，无跨格连续性。
- 云原生三件套（COG/PMTiles/GeoParquet）各自只覆盖一半，且都不可局部编辑。

Weft 的增量贡献：把上述四类工作的**可用内核**（Hilbert 地址、混合细分、
栅格加速、无损要素存储）组合进一个**带版本、带审计、可增量、确定性**的
存储层结构，并用基准逐条验证"优点确实继承、缺点确实消除"。
